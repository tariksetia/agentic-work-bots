## Questions teams ask

![](https://dashpup.ai/dash-character/faq-confused.webp)

Do I need to be technical?+

No. Dash is built for the people who run the business: founders, operators, marketers, customer success leads, finance, agencies. You ask in plain English in Slack or Microsoft Teams. No SQL, no prompt engineering, no formulas, no diagrams. If you can write a team chat message, you can use Dash.

How is Dash different from ChatGPT?+

ChatGPT works with one person at a time, in a private window. Dash works in your team's Slack or Microsoft Teams channels, connects to the tools your company already runs, and posts the finished work back where everyone can see it. What one person sets up, the whole team can use.

How does Dash connect to my tools?+

One-click OAuth via our integration catalog (3,000+ tools). No API keys to manage, no credentials in plaintext, and sensitive workspace secrets are encrypted at rest. If a tool isn't in the catalog, Dash builds a custom integration on the fly.

What platforms does Dash support?+

Dash works in Slack, Microsoft Teams, and on the web. You can chat with Dash, connect tools, upload files, and approve work from any of them. The web app also gives you workspace administration controls.

Can other team members see my private chats with Dash?+

No. Private chats with Dash are scoped to you. Channel work is visible only to people who already have access in Slack or Microsoft Teams. Dash respects each workspace's permission model.

Is my data used to train models?+

No. Your data is workspace-isolated and never used to train models. We use enterprise-grade model APIs with zero data retention.

What if Dash makes a mistake?+

Dash asks before doing anything mutating (sending emails, posting in public channels, writing to your CRM, spending money). For non-mutating reads, every result is shown in thread with sources you can click. If Dash is wrong, reply and it will fix.

How much does Dash cost?+

$50 per workspace per month after a $100 credit. No per-seat math, no contracts. Enterprise tiers available if you need SSO, review logs, or custom data controls.

What is a credit?+

Credits meter Dash's actual work, tool calls, model usage, sandbox runtime. Most tasks cost cents. We show you the credit cost before any large job runs.
